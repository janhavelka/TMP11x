# Reference source intake plan

Prompt 3 downloads **original** exact-part TI PDFs into `docs/reference/source/`,
records URL/revision/license/SHA-256 in `docs/reference/manifest.json`, and
creates source-linked extracted notes. This directory initially contains only
this plan. Reference PDFs and vendor code are not bundled into this promptset
and are not silently part of the eventual production library license/package.

Minimum sources: TMP116 SBOS740A, TMP117 SNOSD82D, TMP119 SNIS236;
TMP114 and TMP118 for an explicit exclusion comparison.
