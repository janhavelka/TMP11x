## Behavior and integration

For a combined register read the controller sends START, the seven-bit address
with the write direction, and the pointer. It then sends a repeated START and
the address with the read direction. The sensor supplies the MSB and LSB. The
controller ACKs the MSB, NACKs the LSB and sends STOP. Each register in a dump
gets its own transfer. The adapter must finish within its callback budget,
including on failure. The sensor's held-line timeout and the caller's budget
start from different events. [116 read diagram, p.22](reference/source/TMP116-Digital-Temperature-Sensor-Datasheet-SBOS740A.pdf#page=22),
[117 read diagram, p.23](reference/source/TMP117-Digital-Temperature-Sensor-Datasheet-SNOSD82D.pdf#page=23),
[119 read diagram, p.25](reference/source/TMP119-Digital-Temperature-Sensor-Datasheet-SNIS236.pdf#page=25).
